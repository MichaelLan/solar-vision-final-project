# Guion del video demostrativo (objetivo: 9:00, máximo 10:00)

**Antes de grabar:** abrir la aplicación pública (https://solar-vision.michaellan-eng.workers.dev/) y comprobar en `/api/model/info` que sirve el modelo **2.0.0** (`architecture: "cnn"`, SHA-256 `11f8b55a…`, el mismo de `artifacts/model.json`). Usar las imágenes de `ml/demo/`, que pertenecen al conjunto de prueba nuevo (procedencia en `ml/demo/provenance.json`; datos de Raptor Maps, licencia MIT). La interfaz muestra los porcentajes con coma decimal (p. ej., 67,8 %). Las cifras de este guion salen de `artifacts/metrics.json`; si el modelo cambia, deben actualizarse.

Se recomienda apoyar las secciones 1 a 4 con cuatro o cinco diapositivas que reutilicen las figuras del informe, en lugar de mostrar archivos JSON.

## Preparación

1. Regenerar el informe (`python3 report/build_report.py` y `typst compile`) y tener abiertas sus figuras o las diapositivas.
2. Probar una predicción en la URL pública justo antes de grabar (alternativa sin red: ejecución local, ver README).
3. Tener a mano las ocho imágenes de `ml/demo/`; no usar imágenes de entrenamiento en la demostración.
4. Ensayar con cronómetro. Si se pasa de 9:30, acortar la sección 6:00–7:45 a dos imágenes.
